Five formats from one kind of brief. Each one shaped to its customer.

Eight published builds, five formats: an explorable briefing, a narrated talk, a leadership twin page, a mission globe and a living operations twin. Each was studied for what made it work, and the shared ingredients now go into every prompt.

References, not templates. Every format here came from the same short, intent-first brief; the model chose the form for each customer. Thumbnails marked "orig" are your originals. The prompt points the model at these builds as the bar, not as a spec. Only the FutureSE talk uses the cisco-3d-stage skill, because that talk is where the skill came from. The other three have no deck navigation, no presenter camera box and no narrated talk track.

    02 · Compose

    Write the brief. Let the model make the masterpiece.

    Every reference build came from the same short, intent-first brief: medium, customer, story and audience, key items, research, one shot, time and masterpiece. Compose builds that brief for you, adds the format as a live reference and the ingredients the best builds share, and leaves the design to the model.

    Before you paste. Use Claude Code (or Cursor) in an empty folder, with web access so it can research and open the reference builds. Type B also needs the cisco-3d-stage skill (see Setup). Sample values filled in. Northwind Health is a made-up customer.
    Advanced Talk your intake out. A step-by-step spoken questionnaire: it reads each question, listens, and fills the fields as you talk. Say "next", "back", "skip" or "done".

    Set up once. Paste a prompt, get the format.
